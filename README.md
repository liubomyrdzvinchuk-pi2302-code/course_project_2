# Job Listing — курсовий проєкт

Багатосторінковий сайт пошуку роботи: головна, вакансії, про нас, блог, сторінка 404.
Інтерфейс двомовний (UA / EN), адаптивний (телефон, планшет, десктоп, Mobile First).

Автор: Любомир Дзвінчук, ПІ-23-02.

## Структура

```
index.html, vacancies.html, about.html, blog.html, 404.html
assets/css/style.css      єдиний mobile-first файл стилів
assets/js/                common.js, ui.js, home.js, vacancies.js, blog.js, about.js, i18n.js
assets/img/               зображення (WebP), CSS-спрайт sprite.png, SVG-спрайт sprite.svg
assets/js/data.js         дані сайту
```

## Що реалізовано

- Семантична верстка, `lang`, унікальні `title`/`description` на кожній сторінці, favicon.
- Бургер-меню, модальне вікно (`<dialog>`) з валідованою формою; закривається кнопкою, Esc і кліком поза вікном.
- CSS-спрайт (іконки категорій) та SVG-спрайт (іконки інтерфейсу).
- Дані з масивів об'єктів малюються через DOM.
- Фільтрація, сортування, пагінація (стан у параметрах URL), слайдер, вкладки, лайки, підписка.
- Перемикач мови UA/EN (статичний текст і дані).

## Запуск локально

Сайт статичний і працює без сервера: у корені проєкту `python3 -m http.server 8080` → http://localhost:8080

Усі дані (вакансії, пости, команда, відгуки) лежать у `assets/js/data.js`, а `common.js` рахує фільтри, сортування й пагінацію в браузері.

## Публікація

GitHub Pages: Settings → Pages → Branch `main`, папка `/root`. Більше нічого розгортати не потрібно.

## Примітки

- HTML-сторінки згенеровано скриптом, але у репозиторії лежать готові файли.
- Фото вирізано з макетів і їх можна замінити оригіналами.
- Пункти меню Price/Pages/Signup/Login з макету не реалізовані.
