# Фото вакансій

Покладіть сюди фото у форматі WebP з такими іменами (квадрат ~400×400 px, до 60 КБ):

| Файл | Вакансія |
|---|---|
| illustrator.webp | Дизайнер-ілюстратор |
| designer.webp | Креативний дизайнер |
| accountant.webp | Бухгалтер |
| chief-accountant.webp | Головний бухгалтер |
| frontend.webp | Frontend-розробник |
| backend.webp | Backend-розробник (Node.js) |
| qa.webp | QA-інженер |
| sysadmin.webp | Системний адміністратор |
| doctor.webp | Лікар-терапевт |
| nurse.webp | Медична сестра |
| civil-servant.webp | Державний службовець |
| records.webp | Спеціаліст з документообігу |
| cook.webp | Кухар |
| restaurant.webp | Адміністратор ресторану |
| journalist.webp | Журналіст |
| smm.webp | SMM-менеджер |

Коли фото додано, відкрийте `assets/js/common.js` і змініть `var USE_JOB_PHOTOS = false;` на `true`.
Якщо якогось файлу немає, сайт показує іконку категорії.
Безкоштовні фото: unsplash.com, pexels.com (вкажіть джерело у звіті).
